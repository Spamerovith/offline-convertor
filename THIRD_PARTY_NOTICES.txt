Offline Convertor uses the following third-party components

FFmpeg (media engine, run as a separate program)
  License: GNU GPL v3 (full build by Gyan Doshi, gyan.dev)
  Source: https://ffmpeg.org and https://github.com/GyanD/codexffmpeg
  The release exe carries an unmodified ffmpeg.exe packed with zstd and unpacks it to
  %LOCALAPPDATA%\OfflineConvertor\engine on first start

libimagequant (PNG palette quantisation)
  License: GNU GPL v3 or later
  Source: https://github.com/ImageOptim/libimagequant

mozjpeg (JPEG encoder)
  License: IJG, BSD-3-Clause, zlib
  Source: https://github.com/mozilla/mozjpeg

ssimulacra2 (perceptual image quality metric, used to pick the JPEG quality)
  License: BSD-2-Clause
  Source: https://github.com/rust-av/ssimulacra2

ureq, rustls (update check over HTTPS)
  Licenses: MIT and/or Apache-2.0, ISC; webpki-roots: CDLA-Permissive-2.0
  Source: https://github.com/algesten/ureq

Enhancement filters (atadenoise, hqdn3d, cas) are part of FFmpeg; cas is an implementation of
AMD FidelityFX Contrast Adaptive Sharpening

oxipng, image, lopdf, pdf-extract, docx-rs, Tauri and other Rust crates
  Licenses: MIT and/or Apache-2.0 (see Cargo.lock for the full list)

Geologica font (ui/fonts)
  License: SIL Open Font License 1.1 (ui/fonts/OFL-LICENSE.txt)
  Source: https://github.com/googlefonts/geologica

better-design interaction kit (ui/css/interaction-kit.css, ui/js/interaction-kit.js)
  License: MIT
